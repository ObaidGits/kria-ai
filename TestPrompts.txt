KEY FOR EXPECTED OUTCOMES
  ✅ GREEN  — Tool executes, result shown
  🔒 PIN    — Policy gate fires; requires typed PIN before execution
  ✅➡️      — Multi-step flow starts (more than one tool call sequenced)
  ❌ BLOCK  — Action should be blocked by safety/policy
  🗣️ VOICE  — Ria should read result aloud + short on-screen text
  ⚠️ WARN   — Warning shown; user choice needed
  📋 PLAN   — StreamEvent::Plan emitted (visible in UI)
  🧠 INTEL  — Intelligence engine active (planner, SelfModel, uncertainty)
  🔍 AUTO   — Autonomous investigation triggered (CuriosityLoop/Perception)
  🧩 SKILL  — Skill compiled from repeated pattern (requires approval)
  🛡️ QUAR   — Dynamic tool quarantined (awaiting HITL approval)
  🌐 BROWSER — Docker-isolated browser task (BrowserAgent)
  🔄 PREEMPT — Voice preemption: active task paused for higher-priority input
